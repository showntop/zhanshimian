A · 色卡类

四根高低不一的色条 · 波浪式起伏
非对称在哪
四根色条高度 62% / 78% / 84% / 96% 各不相同、底部对齐——不是四条等长的色带。选中的两根用 moss 描边抬起，另两根降饱和。
动效
每根错峰 0.42s 上下浮动，周期 4.6s。形成一道从左到右缓缓走过的波——像布料的起伏，不是闪烁。
为什么这样对
色卡本来就是"一卷布样"的隐喻。高低错落让它是布样，等高并排就只是色块表。
背景
两团极慢色雾（23s / 29s）在底层漂移，让整块区域始终有微微的"活"。

B · 对比类

两块错位不等大 · 交替呼吸
非对称在哪
左下 44%×58%，右上 36%×50%——大小不同、对角线错开，不齐平、不对称。下面一行小注给对比的落点。
动效
两块反向呼吸：左边往下 4px 的同时右边往上 6px，周期 5.2s。差异是被"看出来"的，不需要读字。光泽块上的高光缓慢横移，模拟材质反光。
为什么这样对
这是"哑光 vs 光泽"——如果两块一样大并排，眼睛会当成两个色块；错位+反向呼吸之后，它们才像"同一件东西的两种材质"。
克制
动画幅度都在 10px 以内。超越这个量级就从"呼吸"变成"跳动"，会烦。

C · 示意类

刻度轴 · 选中项脉冲
非对称在哪
刻度轴不用居中——线靠左、标签右延伸，三行不等距。选中的那一行点和字同时放大加重，视觉重量明显偏向它。
动效
选中点做pulse：一圈 moss 光环从里向外扩散消失，周期 2.8s。像心跳，安静地提示"是这里"。
为什么不做人形
这一版我明确放弃了画人形——上一轮试过，用 CSS 拼出来的是"药丸+圆"，业余。刻度轴干净、信息明确、不假装自己是插画。

D · 现状对照

就是你现在看到的这一张
问题一：视觉被压成 90px
两个色块挤在 90×90 里，还没有一张图标大。信息量再大也看不出来。
问题二：和下面同语言
它和「发型设计」「穿搭诊断」用的是同一套圆角白卡。工具卡这样没问题，但这条是每天的主角，混在里面就没有主角相。
问题三：静态
完全没有动态。用户划过去，眼睛不会为它停一下。
问题四：文字被截
个性化那段做了 3 行截断，最关键的那句"否则整体会闷"经常被切掉。
对照着看 A/B/C：同样是"一条内容"，出血 + 非对称 + 慢动效之后，它才占据首屏视觉重心，下面那些卡片自动退成背景。
