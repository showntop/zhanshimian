冬天的白，

本白、米白、奶油白——挂在架子上差不多，上身差很多。

你是冷调肤色。本白和冷白贴着皮肤，气色往上走；米白、奶油白里的黄调，会把冷皮衬得发闷。

A · 色彩场

视觉即主角，全屏出血 + 内容咬合
主打
色彩本身就是内容。形象产品的核心是色彩，现在它却缺席。
怎么做
上半屏是流动的色彩场（多层模糊色团，缓慢漂移），真正的色卡浮在场上、选中项抬起； 内容卡咬合上来 30px，形成层次。视觉不占位、不画框，直接出血到屏幕边缘。

冲击力来源
色彩 + 动。每一类内容有专属色彩氛围：色彩类走色谱，版型类走形状，面料类走质感。
成本零：全部 CSS 渐变与动画，无图片、无生成、不触 WebP 红线。
风险：色团模糊在低端机上可能掉帧，需按 prefers-reduced-motion 归零， 且动效只做位移/缩放（不做 filter 动画）。

B · 编辑式

排印即视觉，去掉一切装饰
主打
用字号和留白制造张力，而不是靠图形。像杂志内页，不像 App 卡片。
怎么做
72px 的浅色编号 "02" 压在标题后面，标题 42px 三行断开、字距收紧到 -2px； 视觉缩成一条 44px 的色带（不再是主角）；正文里关键词用下划线强调。

C · 暗场

深底发光，戏剧化
主打
用深底把色彩和照片推出来。浅底上柔和的色卡，在深底上是发光的。
怎么做
底色压到近黑（#20241F），两层发光色团缓慢呼吸；色卡在深底上对比强烈； 文字用 cream 而非纯白，保持品牌的冷调。
