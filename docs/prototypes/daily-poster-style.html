B · 海报式

去容器 · 大字出血 · 单品错落
去掉容器
素材不再套白卡和圆角，靠 mix-blend-mode: multiply 让白底消失、内容融进页面。这一步是从"缩略图"变"杂志页"的分水岭。
大字出血铺底
"全黑 / 不一定瘦" 132px 压在底层，字被屏幕两边裁掉、还旋转 -7°，浅到像是背景纹理。它不承载信息，只提供氛围和重量。
非对称错落
两张图大小不同（200 / 168）、位置错开、各自带一点反向旋转。没有等分，也没有对齐网格。
一处不和谐
右上角一小块橘红胶囊。整页是绿灰调，只有它是暖橙——这一下"刺"出来，页面就活了。只此一处，多一处就乱。
编辑细节
一条贯穿的细线 + 右端 "No. 05"：杂志的页码感，比"第 5 条"这种功能文案有质感。
这一版可以立刻落地：不需要新素材，只改布局与样式。等单件素材到位，错落可以做得更自由。
要验证的两点：① mix-blend-mode 在小程序的兼容性——不支持的话白底会露出来，备选是素材改透明 PNG；② 132px 大字在小屏上的裁切位置，需要真机调。
