三处修正

跨界只需要"跨过"，不需要"深入"
① 跨界封顶
跨界元素底部一律 ≤ hero 底 − 16px，JS 里做 clamp。它永远不可能盖住下方区块。
② 横向分离
跨界元素只占一侧（48%–76% 或 70%–92%），文字容器另一侧留 padding-right。 各占一边，不靠 z-index 硬压。
③ 探出多少
只探出视觉区边界 56px。上一版探了 100+px，那是"深入"不是"跨越"—— 跨界的作用是打破那条线，不是占领文字区。
④ 调试线隔离
安全区、尺寸线全部移进 .guides，默认 display:none。点「调试线」才出现。

换掉例子的原因

色卡类不能用白色系内容
"冬天的白"——色片就是白、米白，在绿白背景上等于没有对比，看着像几片空纸。 色卡这个视觉的价值就是"颜色"，内容必须选有明暗或色相差的。
这版的例子
「你的色域」——冷调皮肤适合的一组颜色，色片之间有明确的明暗和冷暖差，深浅错落之后视觉立刻成立。
如果一定要做"冬天的白"
那就得像色卡实物那样：深底 + 细描边 + 色号。色片上加 no 那样的编号，靠形制而非颜色建立识别。
