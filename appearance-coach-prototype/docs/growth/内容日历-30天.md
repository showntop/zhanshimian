## 0. 时机判断（为什么是现在）

**8 月底 - 10 月是全年最好的切入窗口，一年只有一次。**

- **秋招高峰**：提前批已过，正式批集中在 9-10 月，A 类人群（应届生）需求处于全年峰值
- **换季**：9/23 秋分，穿搭内容自然切换，搜索量抬升
- **开学 / 入职**：9 月是入职高峰，职场新人集中搜索"入职穿什么"

**内容权重建议**：9 月把 60% 的选题压在「面试 / 入职 / 秋招」上，10 月之后逐步回调到常青比例。

## 4. 生产模板（保证质量的下限）

### 4.1 小红书正文结构（以【AI 诊断实录】为例）

```
① 钩子（1 句，痛点或反差，≤20 字）
   例："面试官说我'看着不太敢说话'，我当时没听懂。"

② 我做了什么（2-3 句）
   "上传了正脸、侧脸、全身三张照片，让 AI 做了一次形象诊断。"

③ AI 说了什么（产品真实输出，3 个要点）
   - 当前印象：xxx / xxx / xxx
   - 最值得先改的一处：xxx
   - 三个建议：发型 / 妆容 / 穿搭

④ 我改了什么（3 个具体、可复制的动作）
   1. xxx  2. xxx  3. xxx

⑤ 变化与感受（克制，不吹效果）
   "不是变了一个人，是少了三处'减分项'。"

⑥ 互动引导（合规：提问，不导流）
   "你最想先改的是哪一处？评论区聊聊。"
```

### 4.2 标题公式（6 个可复用模板）

| 模板 | 示例 |
|---|---|
| 数字 + 具体场景 | 秋招第一场面试，这 3 套里我选了第 2 套 |
| 反差 + 结果 | 外套没换，只换了件内搭，整个人亮了一度 |
| 悬念 + 词条 | AI 圈出我穿搭最减分的 3 处，第 1 处我自己都没发现 |
| 否定 + 纠正 | 为什么你的发型"没精神"，问题在颅顶不在长度 |
| 时间 + 过程 | 从形象诊断到改造清单，我用了 21 天 |
| 人群 + 痛点 | 能力够了但看着没分量，AI 说我差在这 2 处 |

**标题硬规则**：必须命中 §2.2 关键词地图中 A/B/C 类至少 1 个词；≤ 22 字；不含极限词。

## 5. 视频化复用规则（不新拍）

一条小红书图文 = 一条视频，不额外生产：

| 素材 | 视频形态 | 平台 |
|---|---|---|
| 【改一处就够】图文 | 图片轮播 + 字幕 + BGM，15-20s | 抖音 / 视频号 |
| 【AI 诊断实录】图文 | 录屏：上传 → 诊断 → 报告，30-45s | 抖音 / 视频号 |
| 【发型实验室】 | 前后对比 + 转场，20-30s | 抖音 / 视频号（主推） |
| 【避坑清单】 | 图文轮播 + 口播，30s | 抖音 / 视频号 |

**视频开头 3 秒必须是钩子原句**（完播率的关键）。

**视频号版本必须额外做一件事**：发布时挂载小程序 —— 这是全链路唯一的一步直达转化。
