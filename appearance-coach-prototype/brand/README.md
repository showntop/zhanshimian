# 怎么打扮品牌标识

## 品牌结构

- 品牌名：怎么打扮
- 产品定位：AI 形象顾问
- 服务范围：发型、妆容、穿搭与场合造型
- 识别策略：完整名称用于产品与推广，单字「扮」用于小程序图标和社交头像。

## 颜色

- 苔绿：`#587344`
- 石墨：`#252725`
- 暖白：`#F8F5F0`

## 文件用途

- `logo-horizontal.svg/png`：官网、推广图、分享海报和社交媒体横版封面。
- `logo-monochrome.svg/png`：单色印刷、合同、备案材料和水印。
- `app-icon.svg/png`：微信小程序头像，建议上传 1024 × 1024 PNG。
- `social-avatar.svg/png`：公众号、小红书、视频号和其他圆形裁切头像。
- `logo-concept-board.png`：品牌方案展示板，不作为正式 Logo 文件直接使用。

## 使用规则

- Logo 四周至少保留一个「扮」字内部横笔高度的留白。
- 小于 120 px 时只使用单字图标，不使用完整字标或副标题。
- 不改变品牌色，不增加渐变、投影、描边、人物剪影或美容工具图标。
- 不把「怎么打扮」拆行，推广标题另行排版时除外。

## 推荐对外文案

- 品牌名：怎么打扮
- 一句话定位：懂发型、妆容和穿搭的 AI 形象顾问
- 小程序简介：上传照片，获得适合你的发型、妆容、穿搭与场合造型方案。
- 社交账号简介：不追潮流模板，只帮你找到更适合自己的打扮方式。

## 图像生成规格

正式方案使用内置 ImageGen 进行方向探索。最终约束为：以「怎么打扮」四字中文
字标为核心，前三字石墨色、末字「扮」为苔绿色；小程序及社交头像只保留
清晰可辨的「扮」字；视觉为现代宋体、编辑感、性别中性、克制且亲和；仅使用
苔绿、石墨与暖白，不使用人物、发型剪影、服装、衣架、美妆工具、问号、渐变、
投影或 3D 效果。完整生成提示词对应的方案展示见 `logo-concept-board.png`。
