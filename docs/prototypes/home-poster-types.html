关于"卡太大"

从 392 降到 300
占屏从 46% 降到 36%，下方从露出 2–3 行变成 3–4 行。 承载块从 62% 高收到 52%，其余元素也等比缩小。
还能更矮吗
能到 272（占屏 32%），但承载块只剩 142px，装下"编号+两行标题+钩子+按钮"已经很紧， 四边几乎没有呼吸。再往下就只能砍钩子或按钮。
我的建议
300 是平衡点：海报感还在，下方也露出足够内容。切换上面的高度按钮直接对比。
七种里 色彩 / 版型 / 比例 / 面料 / 场合 是程序化视觉，零成本零授权； 教程 / 单品 需要真实素材（视频 / 单品图），现在是占位。
一个要注意的：承载块现在是固定尺寸的。 如果哪天标题特别长，文字会溢出承载块——落到其他元素或空白上，对比度就不可控了。 落地时要么限制标题字数上限，要么让承载块按文字高度自适应（推荐后者）。
