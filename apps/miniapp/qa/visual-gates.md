# uplook 小程序视觉验收门禁

每页先答四个问题：主视觉是谁、动效讲了什么、操作是否清楚、是否像 uplook。

## 关键屏基线

| 屏 | 必须保留 | 本轮验收点 |
|---|---|---|
| 首页 | 问候、hero、苔绿 | 1 大 + 2 小工具；场景卡有色温/错位；hero 可呼吸 |
| 拍照 | 三联槽 + 一页提交 | 选中槽放大；取景框；头部不被裁；资料默认可折叠 |
| 分析 | 拱形 + 拍立得 + 进度 | 拱内扫描光带；接近完成时归位；失败有三缩略图 |
| 报告 | tag / 引导线 / drawer | 标注入场错峰；当前照片条数一致；列表与锚点双向联动 |
| 方案 | CompareSlider + 坞 + 三选 | 首次拖动提示；坞与照片有渐隐；收益词不抢 CTA |

## 真机

- iPhone 小屏、主流 iPhone、Android 中端
- 报告标注不挡人脸与 CTA；建档不裁头；方案坞不硬切照片；滑杆跟手 ≥50fps
- 切 tab 回页：图片不闪、入场不重播；隐藏页无多余轮询

## 合规

- 非用户图 100% 带对应标识
- 无评分、无身材羞辱、无医学结论、无警示红
- 错误态与内容不同屏，且给出下一步

## 工程

```bash
pnpm --filter @zsm/design build
pnpm --filter @zsm/miniapp typecheck
node apps/miniapp/scripts/check.mjs
```

主包超限作为独立发布项处理，不通过删视觉资产来过门禁。
