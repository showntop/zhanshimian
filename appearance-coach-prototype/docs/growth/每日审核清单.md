# 每日审核清单

> 这是这份计划里**唯一必须由人完成**的部分。
> AI 负责生产，人负责把关。目标：每天 10-15 分钟过完。
> 用法：打印或贴在显示器旁，逐条勾选。**任何一项不打勾，不放行。**

---

## ⛔ 一票否决项（发现即打回，无需权衡）

出现以下任何一条，内容**直接作废重做**，不要试图"改一下还能用"：

- [ ] ❌ 出现微信号 / QQ / 手机号 / 二维码 / 外链（含截图里的、图片角落的、评论区置顶的）
- [ ] ❌ 出现"私信我""扣 1""主页有惊喜""后台留言""加我"等引导话术
- [ ] ❌ 出现谐音变体导流（VX、微信、绿泡泡、小企鹅、某书、某宝、V 我）
- [ ] ❌ 使用了用户上传的照片、分析报告或任何后台数据
- [ ] ❌ 使用了来源不明的网络图片
- [ ] ❌ 出现颜值/身材打分（"AI 给我打了 X 分""颜值测试"）
- [ ] ❌ 身材羞辱或制造焦虑（"显胖十斤""面试官最讨厌的丑穿搭"）
- [ ] ❌ AI 生成图未标注（法规强制，见下方 §A5）

## A. 单条内容发布前（每条约 2 分钟）

### A1 平台合规

- [ ] 全文（标题 + 正文 + 图片文字 + 话题标签）无任何联系方式
- [ ] 无任何"私信/扣1/主页"类暗示话术
- [ ] 品牌名「怎么打扮」出现方式自然，**不带任何搜索指令词**（不写"微信搜""去搜""小程序见"）
- [ ] 内容为原创，非搬运洗稿

### A2 广告法与表达

- [ ] 无极限词：最、第一、顶级、根治、100%、天花板、永久、绝对
- [ ] 无效果承诺：不变美、不 guaranteed 变好看、不承诺"面试必过"
- [ ] 无虚假前后对比（前后对比必须真实，同一人、同一场景、标注清楚）

### A3 产品价值观

- [ ] 措辞是"可提升点"，不是"缺陷"
- [ ] 建议落到**可执行动作**（换内搭、调腰线、卷袖、改配色），不是"去买新的"
- [ ] 未引导医美
- [ ] 内容确实对应产品的真实能力，**不是凭空编的穿搭知识**

### A4 肖像与隐私

- [ ] 真人素材均已取得书面授权
- [ ] 未使用用户上传照片 / 报告
- [ ] 评论区他人头像昵称未二次使用

### A5 AI 标识（**法规强制**）

> 依据《人工智能生成合成内容标识办法》（2025-09-01 施行），AI 生成的图片需在适当位置、视频需在起始画面添加显著标识。

- [ ] 所有 AI 生成 / AI 编辑的画面已加显著标识（角标「AI 生成示意图」）
- [ ] 正文首段已声明哪些部分是 AI 生成
- [ ] **AI 生成图没有被伪装成真人实拍**
- [ ] 产品 Demo 的发型预览已标注"效果示例"，未声称是本人真实结果

### A6 质量底线（AI 最容易在这里翻车）

- [ ] 标题命中至少一个目标关键词（对照《执行计划》§2.2 关键词地图）
- [ ] 标题 ≤ 22 字，有钩子，不是平铺直叙
- [ ] 首句是钩子，不是自我介绍
- [ ] 建议**具体可执行**（"发根用蓬松粉垫高 2cm" 而不是"注意发型"）
- [ ] 无空话套话（"提升气质""更加自信"这类无信息量的表达）
- [ ] 封面文字 ≤ 12 字，在小图下能看清
- [ ] 结尾是**提问互动**，不是导流

## B. 评论区回复（每天 10 分钟）

### B1 通用规则

- [ ] 回复内容由 AI 起草，**人确认后再发**
- [ ] 回复里不出现任何联系方式、链接、二维码
- [ ] 不主动说"微信搜 / 去小程序 / 私信我"

### B2 遇到"在哪做的 / 用的什么"怎么回

这是最高频也最危险的问题。按风险从低到高：

| 风险 | 回复方式 | 建议 |
|---|---|---|
| 🟢 安全 | 只回内容本身："就是先做了个形象诊断，看清自己现在的问题在哪" | **默认用这个** |
| 🟡 谨慎 | 提及品牌名，不带任何指令："我用的是一个 AI 形象顾问，叫怎么打扮" | 低频使用，一天不超过 2 次 |
| 🔴 禁止 | "微信搜 XX""去小程序""私信我发你""主页有" | 绝对禁止 |

> 原则：**能不提名字就不提**。内容本身足够好，用户会自己搜。

### B3 评论区也是选题库

- [ ] 每天记录 1 条用户真实提问，存进《内容日历》§3 选题池
- [ ] 同一问题被问满 3 次 → 下周必须排一条内容

## D. 每月合规复查（每月最后一天，20 分钟）

- [ ] 回顾本月全部内容，抽查是否有 A 类一票否决项漏网

## E. 危险决策速查表

以下情况**不要自己拍板，先停下来想清楚**：

| 情况 | 为什么危险 | 建议 |
|---|---|---|
| 某条内容数据特别好，想加一条引导 | 爆款内容的导流违规，处罚更重 | 不加。让内容自己长尾发酵 |
| 有人私信问能不能合作/投放 | 涉及商业合作、资质、合同 | 先确认资质与平台报备要求（小红书蒲公英 / 抖音星图） |
| 想用用户自发的分享卡做素材 | 即使用户主动晒，二次商用仍需授权 | 私信取得明确书面授权后再用 |
| 想做"前后对比"引爆点 | 虚假对比是重灾区 | 必须真实，且标注"AI 效果预览"或"实际变化" |
| 想回应用户的负面评价 | 情绪化回复会被截图传播 | 不辩解，只提供事实和解决方案 |
| 平台提示内容"疑似营销" | 申诉成功率低，反复申诉会加重 | 改内容，不要申诉 |
